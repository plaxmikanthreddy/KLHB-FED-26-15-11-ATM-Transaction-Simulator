# Week 2: Java foundations in practice

## Course topic
Variables, data types, Scanner input, arithmetic, and output formatting.

## ATM project goal
Java foundations in practice applied to the ATM Transaction Simulator.

## What this week's code demonstrates
Learning goals:
- Use variables and primitive data types.
- Read numbers with Scanner.
- Apply arithmetic to update a balance.

Test: Try a positive deposit and then zero or a negative deposit.
Git commit: `Week 2 - Add Java input and basic deposit`

## How to run
1. Install a JDK (Java 8 or later; Java 11+ is recommended).
2. Open a terminal in this week's folder.
3. Compile: `javac Main.java`
4. Run: `java Main`

Each week is a standalone learning checkpoint. The code in a later week may replace or reorganize earlier code; it is not intended that all twelve `Main.java` files be compiled together.
