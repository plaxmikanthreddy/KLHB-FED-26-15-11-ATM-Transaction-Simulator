# Week 7: Classes, objects and collaboration

## Course topic
Model accounts and ATM operations using classes and encapsulated fields.

## ATM project goal
Classes, objects and collaboration applied to the ATM Transaction Simulator.

## What this week's code demonstrates
Learning goals:
- Define classes and create objects.
- Keep balance private and expose controlled methods.
- Separate account logic from user interaction.

Test: Verify that outside code cannot directly assign Account.balance.
Git commit: `Week 7 - Introduce Account and ATM classes`

## How to run
1. Install a JDK (Java 8 or later; Java 11+ is recommended).
2. Open a terminal in this week's folder.
3. Compile: `javac Main.java`
4. Run: `java Main`

Each week is a standalone learning checkpoint. The code in a later week may replace or reorganize earlier code; it is not intended that all twelve `Main.java` files be compiled together.
