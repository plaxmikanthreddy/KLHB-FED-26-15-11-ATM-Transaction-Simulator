# Week 12: Declarative data processing and integration

## Course topic
Use streams and lambdas to summarize transaction data.

## ATM project goal
Use streams and lambdas to summarize transaction data.

## What this week's code demonstrates
- Filter and sort records with streams
- use lambdas and method references
- calculate summaries with mapToDouble and sum.

## Test
Run the program and check the withdrawal list, total deposits, total withdrawals, and net movement.

## How to run
1. Install a JDK (Java 8 or later; Java 11+ is recommended).
2. Open a terminal in this week's source folder: `src/week12`.
3. Compile: `javac Main.java`
4. Run: `java Main`

Each week is a standalone learning checkpoint. Compile one week's `Main.java` at a time; these examples are not intended to be compiled together.
