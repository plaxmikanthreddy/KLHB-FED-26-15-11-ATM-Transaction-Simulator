# Week 8: Inheritance, abstraction and safe programs

## Course topic
Represent transactions with an abstract base class and handle runtime input errors.

## ATM project goal
Inheritance, abstraction and safe programs applied to the ATM Transaction Simulator.

## What this week's code demonstrates
Learning goals:
- Use an abstract class and subclasses.
- Apply polymorphism through Transaction.
- Handle invalid numeric input safely.

Test: Enter letters instead of an amount and try an unknown transaction type.
Git commit: `Week 8 - Add transaction abstraction and exception handling`

## How to run
1. Install a JDK (Java 8 or later; Java 11+ is recommended).
2. Open a terminal in this week's folder.
3. Compile: `javac Main.java`
4. Run: `java Main`

Each week is a standalone learning checkpoint. The code in a later week may replace or reorganize earlier code; it is not intended that all twelve `Main.java` files be compiled together.
