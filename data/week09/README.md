# Week 9: Text as reliable program data

## Course topic
Validate text inputs, generate transaction IDs, and format ATM receipts.

## ATM project goal
Validate text inputs, generate transaction IDs, and format ATM receipts.

## What this week's code demonstrates
- Trim and validate strings
- parse numeric text safely
- generate IDs and timestamps
- format a receipt with StringBuilder.

## Test
Try a blank name, unsupported transaction type, and malformed amount.

## How to run
1. Install a JDK (Java 8 or later; Java 11+ is recommended).
2. Open a terminal in this week's source folder: `src/week9`.
3. Compile: `javac Main.java`
4. Run: `java Main`

Each week is a standalone learning checkpoint. Compile one week's `Main.java` at a time; these examples are not intended to be compiled together.

## Suggested Git commit message
`Week 9 - Add transaction IDs and formatted receipts`

## Note
This is an educational ATM simulator, not production banking software.
