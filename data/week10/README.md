# Week 10: Organize, find and persist application data

## Course topic
Save transactions to a text file and search records by transaction ID.

## ATM project goal
Save transactions to a text file and search records by transaction ID.

## What this week's code demonstrates
- Read and append text files using java.nio.file
- handle IOException
- sort records and search by ID.

## Test
Run twice and confirm transactions.txt keeps both records. This teaching example appends a sample deposit record.

## How to run
1. Install a JDK (Java 8 or later; Java 11+ is recommended).
2. Open a terminal in this week's source folder: `src/week10`.
3. Compile: `javac Main.java`
4. Run: `java Main`

Each week is a standalone learning checkpoint. Compile one week's `Main.java` at a time; these examples are not intended to be compiled together.
