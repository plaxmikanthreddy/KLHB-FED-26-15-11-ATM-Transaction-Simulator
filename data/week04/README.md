# Week 4: Iteration and structured problems

## Course topic
Use loops for repeated menus and limit PIN attempts.

## ATM project goal
Iteration and structured problems applied to the ATM Transaction Simulator.

## What this week's code demonstrates
Learning goals:
- Use while and do-while loops.
- Repeat transactions in one session.
- Stop after three failed PIN attempts.

Test: Complete two transactions before exiting.
Git commit: `Week 4 - Add ATM session loop and PIN attempt limit`

## How to run
1. Install a JDK (Java 8 or later; Java 11+ is recommended).
2. Open a terminal in this week's folder.
3. Compile: `javac Main.java`
4. Run: `java Main`

Each week is a standalone learning checkpoint. The code in a later week may replace or reorganize earlier code; it is not intended that all twelve `Main.java` files be compiled together.
