# Week 5: Methods and recursion

## Course topic
Organize behavior into reusable methods; recursion is not needed for ordinary ATM flows.

## ATM project goal
Methods and recursion applied to the ATM Transaction Simulator.

## What this week's code demonstrates
Learning goals:
- Extract reusable methods.
- Pass values as parameters and return updated balance.
- Keep main() easier to read.

Test: Check that invalid deposits and withdrawals do not change the balance.
Git commit: `Week 5 - Refactor ATM using methods`

## How to run
1. Install a JDK (Java 8 or later; Java 11+ is recommended).
2. Open a terminal in this week's folder.
3. Compile: `javac Main.java`
4. Run: `java Main`

Each week is a standalone learning checkpoint. The code in a later week may replace or reorganize earlier code; it is not intended that all twelve `Main.java` files be compiled together.
