# Week 6: Arrays and processing patterns

## Course topic
Record recent transaction types and amounts in fixed-size arrays.

## ATM project goal
Arrays and processing patterns applied to the ATM Transaction Simulator.

## What this week's code demonstrates
Learning goals:
- Store related transaction data in arrays.
- Traverse arrays with a for loop.
- Understand the fixed capacity of arrays.

Test: Record several transactions and display history.
Git commit: `Week 6 - Add transaction history using arrays`

## How to run
1. Install a JDK (Java 8 or later; Java 11+ is recommended).
2. Open a terminal in this week's folder.
3. Compile: `javac Main.java`
4. Run: `java Main`

Each week is a standalone learning checkpoint. The code in a later week may replace or reorganize earlier code; it is not intended that all twelve `Main.java` files be compiled together.
