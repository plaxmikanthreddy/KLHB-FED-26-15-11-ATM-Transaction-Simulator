# Week 11: Collections framework and dynamic data

## Course topic
Use ArrayList, HashMap, Set, and generics for variable-sized data.

## ATM project goal
Use ArrayList, HashMap, Set, and generics for variable-sized data.

## What this week's code demonstrates
- Use Map to look up accounts by ID
- use List for dynamic transaction history
- use Set to track unique transaction IDs
- use enhanced for loops.

## Test
Run the program and check the account balance and generated transaction history.

## How to run
1. Install a JDK (Java 8 or later; Java 11+ is recommended).
2. Open a terminal in this week's source folder: `src/week11`.
3. Compile: `javac Main.java`
4. Run: `java Main`

Each week is a standalone learning checkpoint. Compile one week's `Main.java` at a time; these examples are not intended to be compiled together.
